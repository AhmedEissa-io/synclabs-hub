# SyncLabs Hub

**Central launcher and license manager for SyncLabs AEC tools.**

This repository hosts release files only. Source code is private.

## Download

Go to [**Releases**](https://github.com/AhmedEissa-io/synclabs-hub/releases) to download the latest version.

| File | Description |
|------|-------------|
| `SyncLabsHub-win-Setup.exe` | Installer (recommended) |
| `SyncLabsHub-win-Portable.zip` | Portable — no install needed |

## Auto-update

The Hub checks for updates automatically on startup. When a new version is available,
an **"Update ready"** banner appears — click **Install & restart** and you're done.
